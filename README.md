# 🌍 EcoLife – Environment & Animal Safety Hub

> **Empowering the next generation to protect our planet through education, interaction, and action.**

**EcoLife** is an interactive platform designed to promote environmental sustainability, waste management, and animal welfare. Built with a focus on engaging youth, it combines educational content with quizzes and actionable steps to make saving the planet fun and accessible.

---

## 📖 Quick Overview
EcoLife bridges the gap between awareness and action. We provide a visually engaging interface where users can learn about:
- **Environment Conservation**: Practical tips for waste segregation and carbon footprint reduction.
- **Animal Welfare**: Guidance on adoption, feeding, and protection.
- **Interactive Learning**: Quizzes and challenges to test knowledge.

Participating in **ECWOC’26**? This project is the perfect place to start your open-source journey!

---

## ✨ Features

### 🌿 Environment & Sustainability
- **Waste Segregation**: Learn to Reduce, Reuse, and Recycle with easy guides.
- **Climate Awareness**: Tips on saving energy, planting trees, and reducing carbon footprints.
- **Plant Care**: Basic care instructions for common household plants.

### 🐾 Animal Welfare
- **Adoption & Protection**: Support stray animals and protect endangered wildlife.
- **Responsible Feeding**: Best practices for feeding neighborhood animals safely.

### 📚 Education & Engagement
- **Kids Quiz Section**: Fun, interactive quizzes to teach sustainability concepts.
- **Community Engagement**: Awareness campaigns for community clean-ups.

### 🛠 Utility & Support
- **Report Issues**: Dedicated section to report environmental hazards or animal abuse.
- **Contact**: Reach out for volunteering opportunities.

## 🚀 Getting Started

Follow these steps to get a local copy up and running.

### Prerequisites
- A modern web browser (Chrome, Edge, Firefox, etc.)
- [Git](https://git-scm.com/) installed on your machine.
- A code editor (like [VS Code](https://code.visualstudio.com/)).

### Installation

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/motalib-code/Environment_Animal_Safety_Hub.git
    ```

2.  **Navigate to the Project Directory**
    ```bash
    cd Environment_Animal_Safety_Hub
    ```

3.  **Run the Application**
    - Navigate to the `frontend/src` folder.
    - Open `index.html` in your web browser.
    - *Recommended*: If using VS Code, install the **Live Server** extension and click "Go Live" at the bottom right to run a local development server.
