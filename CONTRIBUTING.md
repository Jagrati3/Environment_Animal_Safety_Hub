## 🛠️ How to Get Started

### 1. Find an Issue
Look through the [GitHub Issues](https://github.com/Jagrati3/Environment_Animal_Safety_Hub/issues). If you find something you'd like to work on, please comment on the issue to let us know, or create a new issue if you find a bug or have a feature idea.

### 2. Fork the Repository
Click the **Fork** button at the top-right of the repository page to create your own copy of the project.

### 3. Clone Your Fork
Clone your forked repository to your local machine:
```bash
git clone https://github.com/your-username/Environment_Animal_Safety_Hub.git
cd Environment_Animal_Safety_Hub
```

### 4. Running Locally
To preview your changes locally using the included Node.js server:
```bash
cd frontend
node server.js
```
The application will be available at `http://localhost:3000`.

### 5. Create a Branch
Create a descriptive branch for your changes:
```bash
git checkout -b feature/your-feature-name
# OR
git checkout -b fix/your-bug-fix-name
```

## 🚀 Contribution Workflow

### 1. Make Changes
- Follow the existing code style (clean HTML5, CSS3, and modern JavaScript).
- Add comments where necessary to explain complex logic.
- Ensure your changes are responsive and look good on all screen sizes.

### 2. Commit Your Changes
Use descriptive commit messages that explain *what* and *why*:
```bash
git add .
git commit -m "feat: add interactive waste management guide"
```

### 3. Push to Your Fork
```bash
git push origin feature/your-feature-name
```

### 4. Open a Pull Request
- Go to your forked repository on GitHub.
- Click **Compare & pull request**.
- Provide a clear title and a detailed description of your changes.
- Reference any related issues (e.g., `Closes #123`).

---

## 📏 Coding Guidelines

- **HTML**: Use semantic HTML5 elements for accessibility and SEO.
- **CSS**: Organize styles logically. Use CSS variables for colors where possible. Ensure mobile responsiveness.
- **JavaScript**: Use ES6+ syntax. Keep code modular and well-documented.
- **Organization**: 
    - Frontend files should be in the `frontend/src/` directory.
    - Assets like images should be placed in appropriate folders.

---

## 🐞 Reporting Issues

If you find a bug or have a suggestion:
1. Go to the **Issues** tab.
2. Click **New Issue**.
3. Use a clear and descriptive title.
4. Provide steps to reproduce the bug (if applicable) and describe the expected vs. actual behavior.
